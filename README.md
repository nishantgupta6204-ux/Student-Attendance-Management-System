# 🎓 Student Attendance Management System 

A web-based Student Attendance Management System developed using **HTML**, **CSS**, **JavaScript**, and **Bootstrap**. The application enables users to manage student records, mark attendance, calculate attendance percentages, and track overall class attendance using browser Local Storage.

---

## 📖 Project Overview

The Student Attendance Management System is designed to simplify attendance tracking in educational institutions. It provides an intuitive interface to add student information, record attendance, calculate attendance percentages, and monitor overall class attendance.

The project demonstrates frontend development concepts, DOM manipulation, Local Storage, and responsive web design.

---

## ✨ Features

- 🔐 Simple Login Authentication
- ➕ Add Student Records
- 👨‍🎓 Manage Student Information
- ✅ Mark Students Present
- ❌ Mark Students Absent
- 📊 Automatic Attendance Percentage Calculation
- 📈 Overall Class Attendance Percentage
